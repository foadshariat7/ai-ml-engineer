This document explains what is required in [`hw06.py`](hw06.py). Implement
every function so its behavior matches its docstring; do not change any
function signature. Each function must be written as a single comprehension
(list, set, or dict, as appropriate) — not a `for` loop with `.append` or
manual key assignment.

## تمرین 6: Comprehensionهای لیستی، مجموعه‌ای و دیکشنری

این سند توضیح می‌دهد که در فایل [`hw06.py`](hw06.py) چه چیزی لازم است. هر
تابع را طوری پیاده‌سازی کنید که رفتار آن دقیقاً با مستندات (docstring) آن

## Functions to implement

### `square_positive(values) -> list[int]`

Return a **new** list containing `value ** 2` for every value in `values`
that is strictly greater than zero, in the original order. Zero and
negative values are excluded entirely — they must not appear as `0` or as
their (negative) square.

<div dir="rtl" align="right">

یک لیست **جدید** برگردانید که شامل `value ** 2` برای هر مقداری در `values`
باشد که دقیقاً بزرگ‌تر از صفر است، به همان ترتیب اصلی. صفر و مقادیر منفی
باید کاملاً حذف شوند — نباید به‌صورت `0` یا مجذور (منفی) خودشان ظاهر شوند.

</div>

### `normalize_names(names) -> list[str]`

Return a **new** list where each name has leading and trailing whitespace
removed and is converted to lowercase, in the original order. A name that
is empty or whitespace-only after stripping must be excluded from the
result entirely.

<div dir="rtl" align="right">

یک لیست **جدید** برگردانید که در آن هر نام، فاصله‌های ابتدا و انتهای آن حذف
شده و به حروف کوچک تبدیل شده باشد، به همان ترتیب اصلی. نامی که پس از حذف
فاصله‌ها خالی یا فقط شامل فاصله باشد، باید کاملاً از نتیجه حذف شود.

</div>

### `unique_lengths(words) -> set[int]`

Return a set containing `len(word)` for every word in `words`. Duplicate
lengths collapse naturally since the result is a set.

<div dir="rtl" align="right">

یک مجموعه (set) برگردانید که شامل `len(word)` برای هر واژه در `words` باشد.
طول‌های تکراری به‌طور طبیعی در هم ادغام می‌شوند، چون نتیجه یک مجموعه است.

</div>

### `score_labels(scores) -> dict[str, str]`

Return a **new** dict mapping every key in `scores` to `"high"` if its score
is greater than or equal to `0.8`, otherwise `"low"`.

<div dir="rtl" align="right">

یک دیکشنری **جدید** برگردانید که هر کلید در `scores` را به `"high"` نگاشت
می‌کند اگر امتیاز آن بزرگ‌تر یا مساوی `0.8` باشد، در غیر این صورت به `"low"`.

</div>

### `keep_valid_scores(scores) -> dict[str, float]`

Return a **new** dict containing every entry from `scores` whose score is
not `None`. A score of `0` or `0.0` is valid and must be kept — checking
truthiness (`if score`) instead of `if score is not None` would incorrectly
drop it.

<div dir="rtl" align="right">

یک دیکشنری **جدید** برگردانید که شامل هر ورودی از `scores` باشد که امتیاز
آن `None` نیست. امتیاز `0` یا `0.0` معتبر است و باید نگه داشته شود — بررسی
truthiness (یعنی `if score`) به‌جای `if score is not None` آن را به‌اشتباه
حذف می‌کند.

</div>

## General rules

- Never mutate an input; every function returns a new collection.
- Use a comprehension for every function — a `for` loop with
  `.append`/manual key assignment does not satisfy the exercise, even if
  it produces the same result.
- Keep the existing type hints and docstrings.
- Replace each `...` with your implementation — don't change signatures.
