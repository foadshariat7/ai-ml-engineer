## Functions to implement

### `clamp_score(score, minimum=0.0, maximum=1.0) -> float`

Return `minimum` if `score` is below it, `maximum` if `score` exceeds it,
otherwise `score` unchanged. Raise `ValueError` if `minimum > maximum`.
Nothing is mutated.

```python
clamp_score(-0.3)  # 0.0
clamp_score(0.6)   # 0.6
clamp_score(1.8)   # 1.0
```

<div dir="rtl" align="right">

اگر `score` کمتر از `minimum` باشد، `minimum` را برگردانید؛ اگر بیشتر از
`maximum` باشد، `maximum` را؛ در غیر این صورت خود `score` را بدون تغییر
برگردانید. اگر `minimum > maximum` باشد، `ValueError` ایجاد کنید. هیچ چیزی
نباید تغییر (mutate) کند.

</div>

### `metric_report(name, *scores, precision=3) -> dict[str, object]`

Return a **new** dict:

```python
{"name": name, "scores": (...), "average": ...}
```

- `scores` must remain a **tuple** in the output (that is what `*scores`
  collects).
- `average` is the mean of the scores, rounded to `precision` places.
- If no scores are supplied, `average` is `None`.
- `precision` is keyword-only naturally, because it follows `*scores` —
  any extra positional number is swallowed by `*scores`.

```python
metric_report("validation", 0.8, 0.9, precision=2)
# {"name": "validation", "scores": (0.8, 0.9), "average": 0.85}
```

<div dir="rtl" align="right">

یک دیکشنری **جدید** برگردانید که شامل `name`، `scores` و `average` باشد.

- `scores` باید در خروجی به‌صورت **tuple** باقی بماند (همان چیزی که
  `*scores` جمع‌آوری می‌کند).
- `average` میانگین امتیازهاست که تا `precision` رقم اعشار گرد شده است.
- اگر هیچ امتیازی داده نشود، `average` برابر `None` است.
- `precision` به‌طور طبیعی فقط-کلیدی است، چون بعد از `*scores` آمده است —
  هر عدد موقعیتیِ اضافه توسط `*scores` جذب می‌شود.

</div>

### `build_config(model, **options) -> dict[str, object]`

Return a **new** dict `{"model": model, **options}`. Every supplied option
becomes an ordinary dictionary entry, and a caller's dict unpacked with
`**` must not be mutated. If someone supplies `model` twice through
argument binding — e.g. `build_config("a", **{"model": "b"})` — Python
itself rejects the duplicate with a `TypeError` before your code runs; you
do not need to check for it.

<div dir="rtl" align="right">

یک دیکشنری **جدید** به شکل `{"model": model, **options}` برگردانید. هر
گزینه‌ی داده‌شده به یک ورودی عادی دیکشنری تبدیل می‌شود و دیکشنری‌ای که
فراخواننده با `**` باز (unpack) کرده نباید تغییر کند. اگر کسی `model` را
دو بار از طریق انقیاد آرگومان (argument binding) بدهد — مثلاً
`build_config("a", **{"model": "b"})` — خود پایتون پیش از اجرای کد شما با
`TypeError` آن را رد می‌کند؛ لازم نیست خودتان آن را بررسی کنید.

</div>

### `apply_transform(values, transform) -> list[float]`

Return a **new** list containing `transform(value)` for every value, in the
original order. Call `transform` **exactly once** per input, and do not
mutate `values`.

```python
def double(value: float) -> float:
    return value * 2

apply_transform([1.0, 2.0, 3.0], double)  # [2.0, 4.0, 6.0]
```

<div dir="rtl" align="right">

یک لیست **جدید** برگردانید که شامل `transform(value)` برای هر مقدار باشد،
به همان ترتیب اصلی. `transform` را برای هر ورودی **دقیقاً یک بار** صدا
بزنید و `values` را تغییر ندهید.

</div>

### `make_threshold_checker(threshold) -> Callable[[float], bool]`

Return a function that returns `True` when its argument is greater than or
equal to `threshold`, otherwise `False`. The returned function must
remember its own threshold, so two independently created checkers never
interfere.

```python
is_high = make_threshold_checker(0.8)
is_high(0.7)  # False
is_high(0.8)  # True
is_high(0.9)  # True
```

<div dir="rtl" align="right">

تابعی برگردانید که اگر آرگومانش بزرگ‌تر یا مساوی `threshold` باشد `True` و
در غیر این صورت `False` برگرداند. تابع برگشتی باید آستانه‌ی خودش را به خاطر
بسپارد، تا دو checker که جداگانه ساخته شده‌اند هرگز با هم تداخل نکنند.

</div>

### `make_running_total(start=0.0) -> Callable[[float], float]`

Return a function that adds its argument to a running total and returns the
new total. Use a **closure** with **`nonlocal`** — no global variable — so
separate instances keep separate state.

```python
total = make_running_total()
total(2.0)   # 2.0
total(3.0)   # 5.0
total(-1.0)  # 4.0
```

<div dir="rtl" align="right">

تابعی برگردانید که آرگومانش را به یک مجموع جاری اضافه کند و مجموع جدید را
برگرداند. از یک **closure** همراه با **`nonlocal`** استفاده کنید — بدون
متغیر سراسری (global) — تا نمونه‌های جداگانه وضعیت (state) جداگانه داشته
باشند.

</div>

### `factorial(value) -> int`

Compute `value!` **recursively**, without `math.factorial`.

- `0! == 1`; positive integers are supported.
- Negative values raise `ValueError`.
- `bool` values must not silently become integers (`True` is an `int`
  subclass) — raise `TypeError`.
- Any other non-`int` runtime value (such as a float) raises `TypeError`.

<div dir="rtl" align="right">

مقدار `value!` را به‌صورت **بازگشتی** و بدون `math.factorial` محاسبه کنید.

- `0! == 1`؛ اعداد صحیح مثبت پشتیبانی می‌شوند.
- مقادیر منفی باید `ValueError` ایجاد کنند.
- مقادیر `bool` نباید بی‌صدا به عدد صحیح تبدیل شوند (`True` زیرکلاسی از
  `int` است) — `TypeError` ایجاد کنید.
- هر مقدار غیر `int` دیگری در زمان اجرا (مثل float) باید `TypeError` ایجاد
  کند.

</div>
