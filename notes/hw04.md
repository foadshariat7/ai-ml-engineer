## The function

### `average_scores(records) -> dict[str, float]`

Each valid record is a dictionary shaped like:

```python
{
    "user_id": "u123",
    "score": 0.82,
}
```

Group the valid scores by `user_id` and return the average valid score for
every qualifying user.

<div dir="rtl" align="right">

هر رکورد معتبر یک دیکشنری با ساختار بالا است. امتیازهای معتبر را بر اساس
`user_id` گروه‌بندی کنید و میانگین امتیازهای معتبر را برای هر کاربر واجد
شرایط برگردانید.

</div>

## Required behavior

### Aggregation

- Ignore records whose `score` is exactly `None`.
- Exclude users whose only scores are `None` — they must not appear in the
  result at all.
- Include scores of `0` and `0.0`; these are valid values, not missing
  ones, so a falsy check like `if not score` is wrong here.
- Accept both integers and floats.
- Return `{}` for an empty input.

<div dir="rtl" align="right">

- رکوردهایی که `score` آن‌ها دقیقاً `None` است را نادیده بگیرید.
- کاربرانی که تنها امتیازهایشان `None` است را حذف کنید — این کاربران نباید
  اصلاً در نتیجه ظاهر شوند.
- امتیازهای `0` و `0.0` را در محاسبه بگنجانید؛ این‌ها مقادیری معتبرند، نه
  مقادیر گمشده، بنابراین بررسی falsy مانند `if not score` در اینجا نادرست
  است.
- هم اعداد صحیح (int) و هم اعشاری (float) را بپذیرید.
- برای ورودی خالی، `{}` برگردانید.

</div>

### Validating `user_id`

Raise `ValueError` when `user_id` is:

- missing;
- not a string;
- empty or whitespace-only.

<div dir="rtl" align="right">

وقتی `user_id` در یکی از حالت‌های زیر باشد، `ValueError` ایجاد کنید:

- موجود نباشد؛
- رشته (string) نباشد؛
- خالی یا فقط شامل فاصله (whitespace) باشد.

</div>

### Validating `score`

- Raise `ValueError` when the `score` field is missing.
- Raise `ValueError` for a negative score.
- Raise `ValueError` for NaN, positive infinity, or negative infinity.
- Raise `TypeError` for a Boolean score, or for any other non-numeric
  type. Remember that `bool` is a subclass of `int`, so
  `isinstance(True, int)` is `True` — Booleans must be rejected
  explicitly.

<div dir="rtl" align="right">

- وقتی فیلد `score` موجود نباشد، `ValueError` ایجاد کنید.
- برای امتیاز منفی، `ValueError` ایجاد کنید.
- برای NaN و بی‌نهایت مثبت یا منفی، `ValueError` ایجاد کنید.
- برای امتیاز Boolean یا هر type غیرعددی دیگر، `TypeError` ایجاد کنید. به
  یاد داشته باشید که `bool` زیرکلاس `int` است، بنابراین
  `isinstance(True, int)` مقدار `True` می‌دهد — پس Boolean را باید
  به‌صراحت رد کنید.

</div>

## General rules

- Process the input records in **one pass**.
- Never mutate the input.
- Use type hints.
- Include a precise docstring.
- Include the record index in every validation error message.
- Replace the `...` with your implementation — don't change the signature.
