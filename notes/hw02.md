## Functions to implement

### `add_loss(loss, history=None) -> list[float]`

Return a **new** list containing every value already in `history`,
followed by `loss`. The `history` argument passed in by the caller must
never be mutated. If `history` is omitted (`None`), start from an empty
history.

<div dir="rtl" align="right">

یک لیست **جدید** برگردانید که شامل تمام مقادیر موجود در `history` باشد و
سپس `loss` به آن اضافه شده باشد. آرگومان `history` که فراخوان (caller) ارسال
کرده هرگز نباید تغییر کند. اگر `history` ارسال نشود (`None` باشد)، از یک
تاریخچه خالی شروع کنید.

</div>

### `add_loss_in_place(loss, history) -> None`

Append `loss` to `history` **in place** (mutate the list the caller
passed in) and return `None`.

<div dir="rtl" align="right">

مقدار `loss` را به‌صورت **درجا (in place)** به `history` اضافه کنید (یعنی
همان لیستی که فراخوان ارسال کرده را تغییر دهید) و `None` برگردانید.

</div>

### `clone_folds(folds, *, deep=False) -> list[list[int]]`

Copy a list of cross-validation folds without mutating the input.

- `deep=False` (default): shallow copy — the outer list is new, but the
  inner lists are the *same objects* as in `folds`.
- `deep=True`: deep copy — the outer list **and** every inner list are
  new, independent objects.
- `deep` is keyword-only (the `*` forbids `clone_folds(folds, True)`;
  you must write `clone_folds(folds, deep=True)`).

<div dir="rtl" align="right">

یک لیست از fold‌های cross-validation را بدون تغییر ورودی کپی کنید.

- `deep=False` (پیش‌فرض): کپی سطحی (shallow) — لیست بیرونی جدید است، اما
  لیست‌های داخلی همان اشیاء موجود در `folds` هستند.
- `deep=True`: کپی عمیق (deep) — هم لیست بیرونی و هم تمام لیست‌های داخلی،
  اشیائی جدید و مستقل هستند.
- پارامتر `deep` فقط به‌صورت کلیدواژه‌ای (keyword-only) قابل ارسال است
  (علامت `*` مانع از `clone_folds(folds, True)` می‌شود؛ باید بنویسید
  `clone_folds(folds, deep=True)`).

</div>

### `same_object(left, right) -> bool`

Return whether `left` and `right` are the exact same object in memory
(identity, i.e. `left is right`) — **not** whether they are equal in
value.

<div dir="rtl" align="right">

بررسی کنید که آیا `left` و `right` دقیقاً یک شیء در حافظه هستند (بررسی
identity، یعنی `left is right`) — **نه** اینکه آیا از نظر مقدار برابرند.

</div>

### `same_value(left, right) -> bool`

Return whether `left` and `right` are equal by value (`left == right`) —
even if they are two distinct objects.

<div dir="rtl" align="right">

بررسی کنید که آیا `left` و `right` از نظر مقدار برابرند (`left == right`)
— حتی اگر دو شیء متفاوت باشند.

</div>

### `shallow_clone_batches(batches) -> list[list[int]]`

Return a shallow copy: a new outer list sharing the same inner list
objects as `batches`.

<div dir="rtl" align="right">

یک کپی سطحی (shallow) برگردانید: یک لیست بیرونی جدید که همان اشیاء لیست
داخلی موجود در `batches` را به اشتراک می‌گذارد.

</div>

### `deep_clone_batches(batches) -> list[list[int]]`

Return a deep copy: a new outer list whose inner lists are also new,
independent objects with the same values as `batches`.

<div dir="rtl" align="right">

یک کپی عمیق (deep) برگردانید: یک لیست بیرونی جدید که لیست‌های داخلی آن نیز
اشیائی جدید و مستقل با همان مقادیر موجود در `batches` هستند.

</div>

## General rules

- Never mutate an input unless the function is explicitly documented to
  do so (`add_loss_in_place` is the only one).
- Keep the existing type hints and docstrings.
- Replace each `...` with your implementation — don't change signatures.
