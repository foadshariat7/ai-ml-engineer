## Exercises

### Exercise 1: Variables and types

Create five variables: your name, your age, your current lesson number,
whether you have completed the lesson, and an optional value that
currently has no value (i.e. `None`). Print each variable's value and
its type (`type(value)`).

<div dir="rtl" align="right">

پنج متغیر بسازید: نام شما، سن شما، شماره‌ی درس فعلی شما، اینکه آیا درس را
کامل کرده‌اید یا نه، و یک مقدار اختیاری که فعلاً هیچ مقداری ندارد (یعنی
`None`). مقدار و type هر متغیر (`type(value)`) را چاپ کنید.

</div>

### Exercise 2: Rebinding and identity

Starting from the given `value = 100`, rebind `value` in turn to a
float, a string, a Boolean, and `None`. After **each** of those four
assignments, print `value`, `type(value)`, and `id(value)` — this shows
that rebinding a name to a new value doesn't mutate the old object, it
just makes the name point somewhere else (hence the changing `id`).

<div dir="rtl" align="right">

با شروع از `value = 100` داده‌شده، `value` را به‌ترتیب به یک float، یک
string، یک Boolean و `None` تغییر دهید (rebind). بعد از **هر یک** از این
چهار انتساب، مقدار `value`، `type(value)` و `id(value)` را چاپ کنید — این
نشان می‌دهد که rebind کردن یک نام به مقدار جدید، شیء قبلی را تغییر
نمی‌دهد، بلکه فقط نام را به جای دیگری اشاره می‌دهد (به همین دلیل `id`
تغییر می‌کند).

</div>

### Exercise 3: Scope (predict, then verify)

The `outer`/`inner` functions below already exist and each define their
own `x`. Without running the file first, predict every line of output
(`inner: ...`, `outer: ...`, `global: ...`). Then:

1. Remove the local `x` inside `inner`. Predict the new output again,
   then run it to check.
2. Also remove the enclosing `x` inside `outer`. Predict again, then
   run it to check.

This demonstrates Python's **LEGB** scope resolution (Local → Enclosing
→ Global → Built-in): a name lookup falls through to the next outer
scope only when it isn't found in the current one.

<div dir="rtl" align="right">

توابع `outer`/`inner` در ادامه از قبل وجود دارند و هرکدام `x` مخصوص به
خود را تعریف می‌کنند. بدون اجرای فایل، خروجی هر خط (`inner: ...`,
`outer: ...`, `global: ...`) را پیش‌بینی کنید. سپس:

۱. `x` محلی (local) داخل `inner` را حذف کنید. دوباره خروجی جدید را
پیش‌بینی کنید، سپس اجرا کنید تا بررسی کنید.
۲. `x` محصورکننده (enclosing) داخل `outer` را نیز حذف کنید. دوباره
پیش‌بینی کنید، سپس اجرا کنید تا بررسی کنید.

این تمرین قانون **LEGB** پایتون برای resolve کردن scope را نشان می‌دهد
(Local → Enclosing → Global → Built-in): جست‌وجوی یک نام تنها زمانی به
scope بیرونی‌تر می‌رود که در scope فعلی پیدا نشود.

</div>

### Exercise 4: Number properties

For the given `number = 17`, determine and print whether it is:

- positive / negative / zero
- even / odd
- divisible by 3
- divisible by 5
- between 10 and 20 (inclusive)

<div dir="rtl" align="right">

برای `number = 17` داده‌شده، تعیین کرده و چاپ کنید که آیا:

- مثبت / منفی / صفر است
- زوج / فرد است
- بر ۳ بخش‌پذیر است
- بر ۵ بخش‌پذیر است
- بین ۱۰ و ۲۰ است (شامل خودشان)

</div>

### Exercise 5: String analyzer

For the given `text = "Artificial Intelligence"`, determine and print:

- the first character
- the last character
- the first 10 characters
- the string reversed (hint: `text[::-1]`)
- the length
- the uppercase version
- the lowercase version
- whether `"Intel"` occurs in the string

<div dir="rtl" align="right">

برای `text = "Artificial Intelligence"` داده‌شده، تعیین کرده و چاپ کنید:

- اولین کاراکتر
- آخرین کاراکتر
- ۱۰ کاراکتر اول
- رشته‌ی معکوس‌شده (راهنمایی: `text[::-1]`)
- طول رشته
- نسخه‌ی حروف بزرگ (uppercase)
- نسخه‌ی حروف کوچک (lowercase)
- اینکه آیا `"Intel"` در رشته وجود دارد یا نه

</div>

### Exercise 6: FizzBuzz

For every number from 1 through 100, print:

- `"Fizz"` if it is divisible by 3
- `"Buzz"` if it is divisible by 5
- `"FizzBuzz"` if it is divisible by both 3 and 5
- the number itself otherwise

<div dir="rtl" align="right">

برای هر عدد از ۱ تا ۱۰۰، چاپ کنید:

- `"Fizz"` اگر بر ۳ بخش‌پذیر باشد
- `"Buzz"` اگر بر ۵ بخش‌پذیر باشد
- `"FizzBuzz"` اگر بر هر دوی ۳ و ۵ بخش‌پذیر باشد
- در غیر این صورت، خودِ عدد

</div>
